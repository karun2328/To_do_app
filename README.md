# 📝 To-Do App

A simple and interactive web-based To-Do list application built using **HTML, CSS, and JavaScript**. This app helps users manage daily tasks efficiently with a clean and minimalistic interface.

---

## 🚀 Features

- ✅ Add new tasks to your list.
- 🗑️ Delete tasks when completed.
- ✔️ Mark tasks as completed (optional enhancement idea).
- 📱 Fully responsive design for mobile and desktop.

---

## 🛠️ Technologies Used

- **HTML** – for structuring the app.
- **CSS** – for styling and responsive layout.
- **JavaScript** – for dynamic task handling and interactivity.

---

## 💻 How to Run

1️⃣ Clone the repository: git clone https://github.com/karun2328/To_do_app.git
2️⃣ Navigate to the project folder: cd To_do_app
3️⃣ Open index.html in your browser.
